# Object-case colours

The initial November 2026 review covered all 600 full entries then present.
Subsequent entries follow the same conventions. The YAML remains the
source of truth; colours are editorial classifications, not inferred from a
verb ending or from the cases in `prepositional_uses`.

## Scope

- Blue (`acc`): a common accusative-object construction in the meanings shown.
- Green (`dat`): a common dative-object construction.
- Purple (`accdat`): both cases are represented, usually in a construction
  with a recipient and a thing, or in separate common meanings.
- Grey (`default`): no Akk/Dat object pattern is highlighted in the usual
  meaning shown. It does not rule out other senses, idioms or special uses.
- Pink (`nom`) and yellow (`modal`) retain their auxiliary/modal conventions.

Include the case of a reflexive pronoun, including obligatory reflexives.
This is a learning convention; it does not claim that every obligatory
reflexive pronoun is analysed as an independent object in every grammar.
Thus `sich erinnern` is blue, `sich merken` is purple, and `sich nähern` is
purple because it combines an accusative reflexive with a dative target.

Do not count a case governed by a preposition as a bare object case. A
freely added beneficiary also does not by itself produce a purple entry:
`etwas kaufen` remains blue. Ordinary constructions with an addressee,
recipient or person deprived of something do count, even when that person
can be omitted. The colour says nothing about whether an object must always
be expressed. Each compact compound needs its own case assessment; its
stem's background is not a classification of that compound.

These distinctions follow the IDS explanations of
[objects and free datives](https://grammis.ids-mannheim.de/progr@mm/6876)
and [reflexive constructions](https://grammis.ids-mannheim.de/progr@mm/6736).

## Decisions worth preserving

The table gives short construction examples, not complete conjugations.
`jdm.` means dative, `jdn.` accusative, and `etw.` the accusative thing in
the examples below.

| Entry or group | Decision and representative construction |
| --- | --- |
| besuchen, reparieren, abonnieren | Blue: `jdn. besuchen`, `etw. reparieren/abonnieren`. |
| bitten, fragen | Blue: `jdn. bitten/fragen`; the person is not a dative object. |
| danken, gratulieren | Green: `jdm. danken/gratulieren`. |
| begegnen, folgen, widersprechen | Green: `jdm. begegnen/folgen/widersprechen`. |
| fehlen, gelingen, genügen | Green: `jdm. fehlen/gelingen/genügen`. |
| gefallen, gehören, passen | Green: `jdm. gefallen/gehören/passen`. |
| helfen, schaden, vertrauen, winken | Green: `jdm. helfen/schaden/vertrauen/winken`. |
| antworten | Green: `jdm. antworten`; `auf eine Frage` does not make the entry blue. |
| erscheinen | Green includes `etwas erscheint mir seltsam`, not just locative `in + Dat`. |
| passieren | Green for `das passiert mir`, the sense "to happen". |
| reagieren | Grey: `auf etw. reagieren`. |
| warten, verzichten, zweifeln | Grey for waiting, doing without and doubting; their prepositional cases do not set the colour. |
| stimmen | Grey for "be correct / vote"; do not borrow the case pattern of `zustimmen`. Tuning an instrument is a separate sense. |
| scheinen, wirken | Grey for the listed meanings "shine" and "appear". |
| gehen, laufen, schwimmen | Grey for ordinary locomotion; route, distance and specialised transitive constructions are not the highlighted pattern. |
| stürzen, tauchen | Grey for "fall/crash" and "dive"; overthrowing or dipping something is a different sense. |
| fahren, fliegen, reiten | Blue includes driving a vehicle, flying an aircraft and riding a horse. Their intransitive uses remain possible. |
| hoffen | Blue includes `das Beste hoffen`; this is distinct from `auf + Akk`. |
| rechnen, reden | Blue includes `eine Aufgabe rechnen` and `Unsinn reden`. |
| gurgeln | Grey for gargling with a liquid; do not borrow the transitive pattern of uttering words in a gurgling voice. |
| nützen, nutzen | `nutzen` remains blue for "use". `nützen` is purple for "benefit" (Dat) and the regional transitive "use" (Akk). |
| erschrecken (intransitive/transitive) | Grey for being startled; blue for frightening someone. |
| sich bedanken, sich freuen, sich interessieren | Blue follows `mich`, despite additional prepositional complements. |
| sich fügen, sich nähern, sich stellen | Purple: `sich (Akk) jdm. fügen/nähern/stellen`. |
| sich merken | Purple: `sich (Dat) etw. merken`. |
| sich teilen | Purple includes `sich (Dat) etw. teilen`; the separate splitting-into-parts construction is omitted from this dative-reflexive table. |
| sich verschreiben | Purple includes `sich (Akk) einer Sache (Dat) verschreiben`; writing incorrectly is another reflexive use. |

These are targeted checks, not a claim that every entry was independently
verified against a dictionary.

The catalogue tests check that backgrounds cover the explicitly recorded
bare object cases and the case of each reflexive pronoun, and preserve
representative corrections. They cannot prove the correctness of all lexical
classifications. Future entries still need an editorial case assessment.
